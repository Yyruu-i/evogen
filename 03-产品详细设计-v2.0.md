### 1.3 Agent 层（Agent Core）← Hermes 继承 + 🆕 MVP 注入点

#### 1.3.1 Agent 主循环（Agent Loop）← Hermes 继承，注入点扩展

```
接口：AgentLoop  ← Hermes 继承

  🆕 MVP 增强伪代码：
    async def run(session: Session, user_message: Message) -> Response:
        # 1. 从进化记忆引擎加载记忆快照 🆕
        memory_snapshot = await evo_memory.get_snapshot(session)

        # 2. 从人格引擎获取当前行为策略 🆕
        persona = await persona_engine.get_active_persona(session)

        # 3. 从经验引擎获取场景关联提示 🆕
        experience_hints = await trace_recorder.get_scene_hints(
            session, user_message.content
        )

        # 4. 从技能引擎匹配适用技能（继承）
        skills = await skill_engine.match_skills(user_message, session)

        # 5. 组装上下文（继承 + 增强）
        context = await context_engine.build_context(
            session, memory_snapshot, persona, experience_hints, skills
        )

        # 6. 开始主循环（继承）
        iteration = 0
        trajectory_turns = []  🆕 轨迹记录
        while iteration < max_iterations:
            if context_engine.estimate_tokens(context) > threshold:
                context = await context_engine.compress(context)

            model = await model_router.select(context, budget)
            response = await llm_call(model, context)

            if response.tool_calls:
                results = await toolchain_manager.dispatch(response.tool_calls)
                trajectory_turns.append({...})  🆕 记录工具调用
                context.append(results)
                continue
            break

        # 7. 后处理（异步）🆕
        asyncio.ensure_future(
            evo_memory.extract_and_store(session, user_message, response, trajectory_turns)
        )
        asyncio.ensure_future(
            trace_recorder.submit_trajectory(session, trajectory_turns, response)
        )

        return response
```

### 1.4 进化层——核心差异化（全部 🆕 MVP 新增）

#### 1.4.1 进化记忆引擎（EvoMemory Engine）🆕 MVP 核心

```
┌─────────────────────────────────────────────────────┐
│              EvoMemory Engine（进化记忆引擎）         │
│                                                      │
│   ┌──────────┐    ┌──────────┐    ┌──────────┐     │
│   │ 瞬态记忆  │ →  │ 工作记忆  │ →  │ 核心记忆  │     │
│   │ (会话内)  │    │ (跨会话) │    │ (永久)   │     │
│   │ TTL:会话  │    │ TTL:衰减 │    │ TTL: ∞   │     │
│   └──────────┘    └──────────┘    └──────────┘     │
│        ↑               ↑               ↑            │
│        │   手动/LLM提取 │   衰减调度     │           │
│        └───────────────┴───────────────┘            │
│                 MemoryManager                       │
│      · 事实提取(LLM) · 向量检索(Chroma)              │
│      · 冲突检测   · 合并去重    · 隐私分级            │
└─────────────────────────────────────────────────────┘

接口：EvoMemoryEngine  🆕 MVP 新增

方法：
  async extract_and_store(
    session: Session,
    user_message: Message,
    assistant_response: Message,
    trajectory: List[TrajectoryTurn]
  ) -> List[MemoryFact]
    # 从交互中提取记忆事实（异步，不影响主循环）
    # MVP 实现方式：
    #   1. 用轻量级 LLM（gpt-4o-mini / deepseek-chat）做零样本事实提取
    #   2. 生成 embedding（OpenAI text-embedding-3-small）
    #   3. 存入 Chroma 向量库 + SQLite 元数据表
    #   4. 与已有记忆做语义相似度匹配（cosine > 0.85 → 合并/冲突检测）
    # MVP 不做自动提取 → 依赖用户在对话中主动说"记住XXX"
    #   或 Agent 在对话中主动问"我是否应该记住这个？"

  async get_snapshot(session: Session) -> MemorySnapshot
    # 获取当前会话的完整记忆快照
    # 快照包含：
    #   - 核心记忆（全量）
    #   - 工作记忆中相关性 > 阈值（0.5）的条目
    #   - 瞬态记忆（全部）
    # 相关性计算：用户消息 embedding × 记忆条目 embedding（Chroma 向量检索）

  async add_manual_fact(fact: ManualFactInput) -> MemoryFact
    # 用户手动添加记忆事实
    # 输入：{content, type, importance?, layer?}

  async update_fact(fact_id: str, updates: FactUpdate) -> MemoryFact
    # 用户编辑已有记忆

  async delete_fact(fact_id: str) -> None
    # 用户删除记忆

  async reinforce(fact_id: str, amount: float = 0.1) -> None
    # 强化记忆（增加权重，延长衰减周期）
    # MVP 版本：用户手动标记「重要」后调用

  async list_facts(
    layer?: "transient" | "working" | "core" | "all",
    type?: "preference" | "fact" | "procedure" | "relationship",
    limit: int = 50,
    offset: int = 0
  ) -> List[MemoryFact]
    # 分页列出记忆事实

  async search_memories(query: str, top_k: int = 10) -> List[MemoryFact]
    # 向量语义搜索记忆

  async get_stats() -> MemoryStats
    # 记忆统计：各层数量、总容量、最近提取时间等

  # 🔮 M1 目标：
  async decay_schedule() -> None
    # 记忆衰减调度（后台定时任务，MVP 不做）

  async detect_contradiction(fact: MemoryFact) -> List[MemoryFact]
    # 矛盾检测，MVP 做基础 cosine 冲突，M1 做 LLM 深度判断

数据结构：
  MemoryFact:
    id: str (UUID)
    type: "preference" | "fact" | "procedure" | "relationship"
    content: str                      # 可读的记忆内容
    embedding: List[float]?           # 向量嵌入（Chroma 存储）
    importance: float                 # 0-1 重要性评分
    weight: float                     # 当前权重（M1 衰减用，MVP 固定 1.0）
    layer: "transient" | "working" | "core"
    source_session_id: str            # 来源会话ID
    source_interaction_id: str?       # 来源交互ID
    created_at: datetime
    updated_at: datetime
    last_accessed_at: datetime
    privacy_level: "public" | "private" | "sensitive"
    tags: List[str]?                  # 用户自定义标签

  MemorySnapshot:
    core_facts: List[MemoryFact]
    working_facts: List[MemoryFact]
    transient_facts: List[MemoryFact]
    generated_at: datetime
    snapshot_id: str

  ManualFactInput:
    content: str                      # "我喝咖啡不加糖"
    type: "preference" | "fact" | "procedure" | "relationship"
    importance: float = 0.5
    layer: "working" | "core" = "working"
    tags: List[str]? = []

  MemoryStats:
    total_facts: int
    by_layer: {"transient": int, "working": int, "core": int}
    by_type: {"preference": int, ...}
    last_extraction_at: datetime?
    total_vector_bytes: int
```

    # 格式：
    #   "## 用户偏好\n- 称呼：张三\n- 回复风格：简洁直接\n- 沟通语气：友好轻松\n..."

  🔮 M1 目标：
  async suggest_evolution(history: List[Interaction]) -> PersonaDelta
    # 基于长期交互历史建议人格调整（需用户确认）
    # 例如：「检测到你最近 10 次对话都要求"详细解释"，建议提高 detail_level」

  async progressive_discovery(session: Session) -> Question?
    # 渐进式了解用户，在自然对话中提问
    # 前 10 次交互中收集 ≥5 个关键属性

数据结构：
  Persona:
    # 基础属性
    display_name: str?               # 用户称呼
    preferred_language: str = "zh"   # 偏好语言
    timezone: str?                   # 时区

    # 回复风格
    conciseness: float               # 0-1 简洁程度（0=详细, 1=极简）
    formality: float                 # 0-1 正式程度
    warmth: float                    # 0-1 友好/温暖程度
    directness: float                # 0-1 直接程度

    # 功能偏好
    auto_approve_tools: bool         # 是否自动批准安全工具
    show_thinking: bool              # 是否显示思考过程
    response_language: str = "zh"    # 回复语言

    # 学习到的偏好
    learned_preferences: Dict[str, any]  # 从交互中学到的动态偏好

    # 元数据
    created_at: datetime
    updated_at: datetime
    discovery_questions_asked: int   # 已提问的渐进式了解问题数

## 七、关键非功能设计

### 7.1 隐私设计（Privacy by Design）

```
原则：
1. 本地优先：所有记忆默认存储在 ~/.evogen/data/（SQLite + Chroma）
2. 分级隐私：
   - public: 可同步到云（未来功能）
   - private: 仅本地存储（默认）
   - sensitive: 加密本地存储（使用 SQLCipher / 文件级加密）
3. 遗忘权：
   - 用户可随时删除任意记忆 → SQLite DELETE + Chroma DELETE 同步
   - 记忆浏览器提供完整「这条记忆来自哪里」的溯源
4. 数据导出：一键导出全部记忆为 JSON（M1）
5. 不依赖云端：Agent 核心功能不要求网络连接（仅 LLM 调用需要）
```

### 7.2 安全防护层次

```
Layer 1 - 网络层：
  DM 配对码验证（新设备）+ Token 认证 + TLS（可选）
Layer 2 - 会话层：
  危险命令审批（继承 Hermes approval 机制）
Layer 3 - 执行层：
  Docker 沙盒执行危险操作 / 本地进程执行安全操作
Layer 4 - 数据层：
  API Key 存储于 .env（不落盘明文配置）
  审计日志：所有操作记录（继承 Hermes）
```

### 7.3 性能目标与优化策略

| 指标 | MVP 目标 | 优化策略 |
|------|:---:|------|
| **首响应时间（TTFR）** | < 2 秒 | 流式输出（继承 Hermes） |
| **记忆检索延迟** | < 500ms | Chroma 向量索引 + 热记忆缓存（Python dict LRU） |
| **事实提取延迟（异步）** | < 3 秒 | 轻量 LLM，不阻塞主循环 |
| **上下文组装** | < 100ms | 预计算 embedding 复用；Chroma query batch |
| **并发会话数** | ≥ 50（MVP） | asyncio 异步 + 连接池 |
| **Token 消耗优化** | 比基线减少 30% | 记忆感知压缩（F-010） |
| **数据库操作** | SQLite WAL 模式 | 读写并发分离 |
